# Музыка в Pultra

Верхний бар показывает «Pultra / Музыка». «Витрина», Discovery и «Сеанс» доступны ролям admin и media. Витрина строится по реальной коллекции Jellyfin: жанр сужает список исполнителей и альбомов, обложка открывает треки, а «Слушать вперемешку» перемешивает всю доступную коллекцию. Аудио продолжает играть при переходах между страницами. Возврат в «Сеанс» открывает ту же очередь.

## Подключение

Используются существующие `JACKETT_*`, `QBITTORRENT_*` и `JELLYFIN_*`. Музыка сохраняется в `QBITTORRENT_SAVE_ROOT/MEDIA_MUSIC` (по умолчанию `/data/music`). Это должен быть тот же каталог хоста, который Jellyfin видит как `/media/music`. Для подготовки музыкальной библиотеки на штатном стенде см. [инструкцию homelab](../homelab/README.md). Доступ к каталогу и оригиналу требует личного пользователя Jellyfin, привязанного к учётной записи Pultra. После привязки нужно войти заново.

Поисковый запрос Discovery отправляется в аудиокатегории настроенных индексаторов Jackett. Пустой запрос показывает недавние раздачи. На карточке FLAC обозначает формат, заявленный источником. Битность и частоту Pultra показывает по данным файла, когда он уже в Jellyfin. Для открытых концертных записей включите [индексатор Live Music Archive](../homelab/jackett/). Полный торрент может содержать обложки и дополнительные форматы. Выбранная раздача поступает в qBittorrent с категорией `mc-music`; действует общая с фильмами квота пользователя. После завершения Pultra запрашивает сканирование Jellyfin.

Исходный файл передаётся через HTTP Range по ограниченному временному билету. Pultra не транскодирует его и не передаёт в браузер ключ или персональный токен Jellyfin. Если браузер не декодирует контейнер или кодек, плеер показывает ошибку. Это не гарантия bit-perfect вывода на устройстве.

## Плейлисты и предпочтения

В Discovery выберите файлы плейлистов: один или несколько JSON/CSV/TXT либо ZIP. Зашифрованный архив сначала распакуйте самостоятельно. Поддерживаются объекты `{playlists:[{name,tracks:[{artist,title}]}]}`, одиночные плейлисты, экспорты с полями `track.title` и `artists[].name`, CSV с заголовками исполнителя и трека, текст «Исполнитель — Трек». Схема архива Яндекс ID зависит от содержимого выгрузки; историю прослушивания и списки только с ID нельзя импортировать как именованные плейлисты. До записи Pultra показывает число списков и треков. Импорт не загружает аудио; треки, которых нет в коллекции, можно искать отдельно.

Чтобы выгрузить собственные и сохранённые плейлисты и «Мне нравится» из аккаунта с уже имеющимся музыкальным OAuth-токеном, на личном компьютере выполните:

    python3 tools/export_yandex_music.py ~/Downloads/music-playlists.json

Токен вводится скрыто и используется только для запросов к api.music.yandex.net. Выгрузка использует неофициальный API Яндекс Музыки; возможны изменения на стороне сервиса. Удалённые или недоступные треки без метаданных перечисляются в `unavailable`. Не отправляйте токен в чат или на сервер Pultra. Для получения персонального архива есть также [инструкция Яндекс ID](https://yandex.ru/support/id/ru/personal-data).

Плейлисты и лайки изолированы по пользователям Pultra. Повторный импорт обновляет одноимённые списки; порядок и повторения треков сохраняются. В «Для вас» учитываются исполнители импортированных списков и жанры любимых локальных треков.

## API

- `GET /api/music/library`: альбомы, треки, формат, видимый пользователю каталог.
- `GET /api/music/releases?q=...`, `POST /api/music/releases/:id/grab`, `GET /api/music/downloads`: поиск, выбор раздачи и статус загрузок пользователя.
- `POST /api/music/tracks/:id/play`: временный адрес оригинала для HTML audio.
- `GET /api/music/taste`, `PUT|DELETE /api/music/taste/likes/:id`, `POST /api/music/taste/playlists`: личные предпочтения и списки.
- Инструменты Hermes: `search_music_releases`, `grab_music_release`, `get_music_downloads`. У Hermes отдельная очередь и свои идентификаторы результатов.
