# Музыка Pultra — реализация согласованной витрины

Цель: перенести витрину, Discovery и сеанс из рассмотренного прототипа в React-приложение. Верхний бар всех разделов показывает знак из трёх колец и «Pultra / раздел». Демоданные не служат источником для рабочего приложения.

1. Общая шапка и маршруты: /music, /music/discovery, /music/session; роли admin и media. Сохранить меню, темы, квоту и вкладки в верхнем баре.
2. Каталог и звук: библиотека Jellyfin в контексте пользователя; получить настоящие треки, объединить по альбомам, открыть только проверенный Audio этого пользователя по ограниченному билету. Range, оригинальный кодек, без видео-HLS и секретов в URL.
3. Раздачи: музыкальные категории Torznab, только релизы с заявленным FLAC, выбор через серверный идентификатор, квота, категория qB, отдельная папка music. После завершения — индексирование Jellyfin. Поиск не зависит от наличия альбомов.
4. React: фильтры жанра/исполнителя, обложки, альбом и shuffle всей коллекции; единая очередь с переходом в сеанс, непрерывный звук; Discovery с новинками, подборками, поиском изданий, лайками и импортом плейлистов.
5. Проверка: авторизация чужого/неаудио объекта, Range, поиск без утечки ссылок, квота, повторный grab, пустая библиотека, отказ интеграции, обе роли, мобильная шапка и смена маршрутов при воспроизведении. Прогнать сборки, backend и браузерные проверки.
